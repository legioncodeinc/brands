Square icon-only button (36px, or 28px with `small`) for row actions, close, copy.

```jsx
<IconButton icon="more-horizontal" label="Log actions" small />
```

Props: icon: string; label: string; small?: boolean; variant?: 'default'|'destructive'|'outline'|'secondary'|'ghost'; disabled?: boolean; onClick?: () => void; style?: React.CSSProperties;
