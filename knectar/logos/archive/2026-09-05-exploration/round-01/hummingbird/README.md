# knectar hummingbird logo options

Four original vector concepts prepared on 5 September 2026. These are options for selection, not an approved master brand.

- **A / Swift:** the compact bird from the initial exploration.
- **B / Hover:** a rounded raised wing, upright flight posture, and fine bill. Recommended for its direct hummingbird association and balance beside the lowercase wordmark.
- **C / Vector:** a faceted construction closest to the angular marks in the existing brand family.
- **D / Flow:** a longer, more fluid flight silhouette.

All four share the same outlined Inter SemiBold wordmark, spelled `knectar`, to make the symbol comparison fair. Each has one green wing in `#3DDC97`, an ink (`#0A0B0D`) version for light surfaces, and a white (`#F5F6F7`) version for dark surfaces.

## Files

- `svg/`: scalable logos and separate icons. Wordmarks are outlines, so no font installation is required.
- `png/`: 2,000-pixel-wide horizontal logos and 512-pixel-square icons with real alpha transparency.
- `knectar-logo-options-round-01.zip`: all 32 SVG and PNG files.
- `review/verification.json`: exported PNG dimensions and alpha-channel results.
- `review/contact-sheet.png`: internal visual QA on light and dark surfaces. This proof image has backgrounds; all artwork in `svg/` and `png/` is transparent.

The bill and tail tips become fine at favicon sizes. The comparison includes 16, 32 and 64 pixel previews; a selected master should receive an optically simplified favicon variant before final brand-kit production.

## Reference review

Reviewed the repository root README, Legion README and design skill, Legion logo exports, OSPRY logo exports and guide, SHRKE bird and wordmark, MACSITNA lockup, WHIPT logo source, Llama Force artwork, and My Identity Provider image. The strongest recurring family traits are neutral silhouettes, green accents, Inter typography, and geometric animal marks. The My Identity Provider PNG examined is a purple gradient field and was not used as the direction for knectar.

Product context was informed by [Portkey](https://portkey.ai/) and [Maxim's current homepage](https://www.getmaxim.ai/), which presents Bifrost's gateway, governance, and observability. The hummingbird offers a name association through nectar and a visual association with speed and precision. No competitor mark was copied.

Construction: original authored SVG geometry with outlines from the repository's Inter font, rendered losslessly to PNG. No image-generation model was used. The existing assets were preserved.
