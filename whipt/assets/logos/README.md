# WHIPT logos

The approved WHIPT identity uses whippet artwork and the shared outlined WHIPT wordmark.

- **Pursuit** is the default mark used by the design demo and token library.
- **Full Stride** is the approved alternative.
- [Open the asset catalog](whippet-brand-kit-v1/index.html) to browse both directions, all color treatments, and SVG/PNG downloads.
- [Download the complete kit](whipt-complete-brand-kit-v1.zip), [Pursuit](whipt-pursuit-assets-v1.zip), or [Full Stride](whipt-full-stride-assets-v1.zip).

The top-level files are compatibility copies of the approved Pursuit exports:

| File | Artwork |
| --- | --- |
| `whipt-logo-light.svg` / `whipt-logo-dark.svg` | Horizontal Pursuit lockup |
| `whipt-symbol-light.svg` / `whipt-symbol-dark.svg` | Pursuit symbol centered in a transparent square |
| `whipt-symbol.svg` | Same square symbol; silhouette follows `currentColor`, mint remains fixed |
| `whipt-wordmark-light.svg` / `whipt-wordmark-dark.svg` | Shared outlined WHIPT wordmark |
| `whipt-favicon.svg` | Pursuit on a solid dark square |

Light and dark filenames name the intended background. Use the [vector masters and usage guide](whippet-brand-kit-v1/README.md) when preparing additional exports.
