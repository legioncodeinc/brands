Stroke icon from the rflectr subset of Lucide; use for navigation, actions, and status glyphs — never emoji or unicode symbols.
```jsx
<Icon name="route" size={16} />
<Icon name="alertTriangle" color="var(--text-warn)" title="Warning" />
```
Sizes: 14 (inline text), 16 (controls, default), 20 (nav, empty states). Decorative by default; pass `title` to make it accessible.
